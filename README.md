
# Cary｜在庫管理Webアプリ

## 概要
EHIME TECHで制作した在庫管理Webアプリケーションです。物品の使用状況や在庫数を管理することを目的に開発しました。

## 主な機能
- 物品の使用記録
- 在庫数の一覧表示
- 在庫が少ない物品の確認
- 食品・備品・文房具のカテゴリ別管理

## 使用技術
HTML / CSS / JavaScript / PHP / MySQL / Bootstrap

## 制作における役割

在庫管理を効率化するWebアプリケーションのアイデアを考案し、必要な機能や画面構成を検討しました。

プログラミングについては、専門家の指導を受けながらHTML、CSS、JavaScript、PHP、MySQLを学び、自らコードの入力・修正を行って制作しました。

開発を通じて、アイデアを実際に動くアプリケーションとして形にする経験を積みました。

## 動作環境
XAMPPを用いたローカル環境で動作確認済みです。
